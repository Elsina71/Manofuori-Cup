# Regole di lavoro (Manofuori Cup)

Regole decise dal titolare: valgono per ogni sessione e per ogni modifica.

## Come lavorare con il titolare
- **Lingua**: si risponde nella lingua in cui scrive il titolare: se scrive in italiano si risponde in italiano,
  se scrive in inglese si risponde in inglese.
- **Skill indicate dal titolare**: se il titolare dice di usare determinate skill (per esempio "usa UI e Taste"),
  si usano quelle e basta, per intero, senza decidere da soli di usarle solo in parte o di sostituirle.
  Se si pensa che una skill non sia adatta, si fa una proposta e si **chiede conferma prima** di procedere.
- Le modifiche si fanno solo in questo repository (`Elsina71/Manofuori-Cup`): il referto elettronico è
  `referto-indoor/` qui dentro. Beach+ Arena (repository principale) non si tocca.
- Prima di pubblicare: prove (unità, regole del database, browser) e verifica che la pubblicazione su GitHub
  Actions sia andata a buon fine; il sito è https://manofuori.it.
